## 🚀 Featured Projects

### 🏦 PayVault: Employee Performance & Payroll Management Platform
Role-based payroll and performance platform with separate dashboards for **Admin, HR and Employee**.
- **Stack:** Spring Boot, Spring Security, JPA/Hibernate, PostgreSQL
- **Deployed on AWS:** EC2 + RDS PostgreSQL, Nginx reverse proxy, systemd service
- Role-based access control (`ROLE_ADMIN`, `ROLE_HR`, `ROLE_EMPLOYEE`)

### 📦 Enterprise Inventory & Order Management System
Microservices backend with **4 independent services**: Auth, Inventory, Order and Notification.
- **Stack:** Spring Boot, JWT, PostgreSQL (database per service), RestTemplate, Docker
- Layered architecture with a universal `ApiResponse<T>` wrapper and `GlobalExceptionHandler`
- **Live deployment:** Render (Docker) + Neon PostgreSQL
- 🔗 [Source Code](https://github.com/DivyanshSingh27/inventory-order-management-system)
