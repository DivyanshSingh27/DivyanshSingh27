### Selected Engineering Work

#### [Enterprise Inventory & Order Management System](https://github.com/DivyanshSingh27/inventory-order-management-system)
`Java 17` · `Spring Boot` · `Microservices` · `JWT` · `PostgreSQL` · `Docker` · `Render`

Distributed backend decomposed into **4 autonomous microservices** (`auth-service`, `inventory-service`, `order-service`, `notification-service`), each owning an isolated Neon PostgreSQL database.
- Implemented inter-service REST orchestration via `RestTemplate` with automated inventory stock restoration upon order cancellation.
- Enforced uniform error and payload contracts across all services using a generic `ApiResponse<T>` wrapper and `@RestControllerAdvice` global exception handling.
- Containerized individual services with Docker and automated end-to-end smoke testing against live cloud deployments.

#### PayVault — Employee Performance & Payroll Platform
`Java` · `Spring Boot` · `Spring Security` · `JPA/Hibernate` · `PostgreSQL` · `AWS EC2/RDS` · `Nginx`

Multi-role enterprise payroll and appraisal system enforcing strict access boundaries across `ROLE_ADMIN`, `ROLE_HR`, and `ROLE_EMPLOYEE`.
- Built stateless JWT authentication and method-level authorization filters to isolate sensitive compensation records.
- Provisioned and deployed the production stack on **AWS EC2** connected to a managed **AWS RDS PostgreSQL** instance, fronted by an **Nginx** reverse proxy and managed via `systemd`.

#### Additional Systems
- **Asset Maintenance Manager:** Full-stack equipment lifecycle and maintenance tracker built with Java Servlets and PostgreSQL.
